# Night Stalker: Abandoned Heist (ขโมยล่าท้าผี)

เกมแนว **Thief + Horror Survival (ขโมยของ + เอาชีวิตรอดจากผี)** สไตล์ Pixel Art 16-bit ผสมผสานบรรยากาศ Retro Analog Horror (FNAF / REPO / Lethal Company)

---

## 🎮 ฟีเจอร์หลักของเกม (Core Features)

### 1. 📺 หน้าเมนูหลักสไตล์ Analog Horror (FNAF Style)
- **ฝั่งขวา**: ตัวละครโจรหนุ่มนั่งพักผ่อน จิบกาแฟ และเตรียมไฟฉายใน Safehouse พร้อมจอ CRT วงจรปิดที่ตรวจจับความเคลื่อนไหวในคฤหาสน์
- **ฝั่งซ้าย**: เมนูเลือกเข้าเล่นเกม (`START HEIST`), ร้านค้ามืด (`BLACK MARKET`), ตั้งค่า (`SETTINGS`), วิธีเล่น (`CONTROLS`)
- **บรรยากาศ & เอฟเฟกต์**: เส้นสแกนแบบจอแก้ว (CRT Scanlines), แสงไฟกระพริบ, เสียง Synth Horror Drone หม่นหมอง

### 2. 🛒 ร้านค้ามืด & การอัปเกรด (Black Market & Upgrades)
- **หมวดอุปกรณ์ & ไอเทมเสริม**:
  - 🔫 **Stun Taser Gun**: ปืนช็อตผีเพื่อสตั้นเป็นเวลา 4-6 วินาที ช่วยให้มีเวลาวิ่งหนีหรือเข้าตู้ซ่อน
  - 👟 **Stealth Boots**: รองเท้าเดินเงียบ เพิ่มความเร็วและลดเสียงฝีเท้า
  - 📻 **Spirit EMF Detector**: เครื่องสแกนวิญญาณ ส่งเสียงบี๊บเตือนเมื่อมีผีอยู่ใกล้ห้อง
  - ⚡ **Adrenaline Shot**: ยาฉีดกระตุ้นพลัง วิ่งไว 100% โดยไม่สนน้ำหนักกระเป๋า 15 วินาที
  - 🔋 **Extra Battery**: ถ่านชาร์จไฟฉายสำรอง เติมพลังงานเต็มทันที
- **หมวดอัปเกรดความสามารถถาวร (Levels 1 - 5)**:
  - 🔦 **Flashlight Battery**: ยืดอายุแบตเตอรี่และขยายระยะแสง
  - 🎒 **Backpack Capacity**: เพิ่มขีดจำกัดน้ำหนักกระเป๋า (12kg -> 30kg)
  - 💥 **Taser Voltage & Ammo**: เพิ่มจำนวนกระสุนปืนช็อตและระยะเวลาสตั้น
  - 🏃 **Speed & Stamina**: เพิ่มความเร็ววิ่ง Sprint และการฟื้นฟู Stamina

### 3. 🏚️ ระบบเกมเพลย์ในบ้านร้าง (In-Game Gameplay)
- **🎒 ระบบน้ำหนักกระเป๋า (Weight System)**:
  - ของแต่ละชิ้นมีมูลค่า ($) และน้ำหนัก (kg) ที่แตกต่างกัน
  - ยิ่งกระเป๋าหนัก ตัวละครจะยิ่ง**เดินช้าลง** และเสียงฝีเท้าจะดังขึ้น ล่อผีได้ง่ายขึ้น
  - กด `[Q]` เพื่อทิ้งของที่หนักที่สุดออกมาเมื่อต้องวิ่งหนีฉุกเฉิน
- **👻 ระบบผีและการออกล่า (Ghost AI & 10% Curse Chance)**:
  - ผีลอยวนเวียนตามห้องต่างๆ ในคฤหาสน์ (Phantom วิญญาณเรืองแสง & Shadow Wraith)
  - ทุกครั้งที่เก็บของ มีโอกาส **10%** ที่คำสาปจะทำงาน ไฟจะกระพริบและผีจะเริ่มออกล่าทันที!
  - ผีจะตรวจจับจากแสงไฟฉายและเสียงฝีเท้าหนัก
- **🚪 ระบบตู้ซ่อน (Hiding Closets)**:
  - กด `[E]` เพื่อเข้าไปหลบในตู้เสื้อผ้า มุมมองจะเปลี่ยนเป็นช่องมองแอบดู (Slit View)
  - หากหลบทัน ผีจะเดินผ่านไปและยกเลิกการไล่ล่า
- **🏃 ระบบกระโดดข้ามสิ่งกีดขวาง (Jumping Mechanic)**:
  - มีเศษกระจกแตก, แผ่นไม้ตะปู, และกับดักหมีตามพื้น
  - กด `[SPACE]` เพื่อ**กระโดดข้าม**สิ่งกีดขวางได้อย่างปลอดภัย ไม่โดนสโลว์และไม่เกิดเสียงดัง
- **🚚 ระบบส่งยอดโควต้า & ขายของ (Repo Quota System)**:
  - ขนของกลับมาที่ท้ายรถตู้ (VAN) ของจะถูกขายและคิดเป็นเงินยอดโควต้าประจำคืนทันที
  - เมื่อยอดครบตามกำหนด กด `[E]` ที่รถตู้เพื่อหลบหนี (EXTRACT), รับเงินโบนัส, ไปช้อปปิ้ง และเริ่มคืนถัดไปที่ท้าทายขึ้น!

### 4. 😱 ระบบเสียงหลอน & Jumpscare
- ระบบเสียง Procedural Web Audio API (เสียงก้าวเท้า, ไม้ลั่น, กริ๊กไฟฉาย, วิทยุหวีด, เสียงหัวใจเต้นเร็วเมื่อผีไล่)
- **Jumpscare**: เมื่อถูกผีจับได้ หน้าจอจะสั่นรุนแรงพร้อมภาพผีตาแดงกรีดร้องและเสียงสะพรึงขวัญ!

## ⌨️ ปุ่มควบคุม (Controls)

| ปุ่ม | การทำงาน |
| :--- | :--- |
| `W / A / S / D` หรือ ลูกศร | เดินสำรวจ 8 ทิศทาง |
| `SPACE` | **กระโดด (JUMP)** ข้ามสิ่งกีดขวางบนพื้น |
| `SHIFT` | วิ่งเร็ว Sprint (ใช้ Stamina) |
| `E` | เก็บของ / ซ่อนในตู้ / เปิด-ปิดประตู / ส่งของหลบหนีที่รถตู้ |
| `F` | เปิด / ปิด ไฟฉาย |
| `คลิกซ้าย (Mouse Left)` | ยิงปืนช็อตผี Stun Taser |
| `Q` | ทิ้งของชิ้นที่หนักที่สุดในกระเป๋า |
| `1` | ใช้ยาบัฟ Adrenaline (วิ่งไวไม่สนน้ำหนัก 15 วินาที) |
| `2` | ชาร์จแบตเตอรี่ไฟฉาย 100% |
